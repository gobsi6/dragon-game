# 용의 대륙 (1단계)

드래곤이 되어 대륙을 떠도는 지인용 웹 텍스트 게임입니다.
지금 들어 있는 기능: 계정, 드래곤 만들기, 지역 이동, 같은 지역 드래곤 보기, 지역 채팅.

## 실행하기

1. Node.js 20 이상을 설치합니다. (https://nodejs.org 에서 LTS 버전)
2. 이 폴더에서 터미널을 열고 한 번만 설치합니다.
   ```
   npm install
   ```
3. 서버를 켭니다.
   ```
   npm start
   ```
4. 브라우저에서 http://localhost:3000 에 접속합니다.

처음 만든 계정이 GM 계정이 됩니다. (GM 기능은 다음 단계에서 붙일 예정)

## 친구들과 같이 접속하기

- 같은 와이파이라면: 내 PC의 내부 IP로 접속 (예: http://192.168.0.12:3000)
- 바깥에서 접속하려면: Cloudflare Tunnel을 쓰면 간단합니다.
  `cloudflared`를 설치한 뒤, 서버를 켠 상태에서 아래를 실행하면 공유용 주소가 나옵니다.
  ```
  cloudflared tunnel --url http://localhost:3000
  ```
  이 임시 주소는 실행할 때마다 바뀝니다. 고정 주소가 필요하면 나중에 호스팅으로 옮기면 됩니다.

서버를 켠 PC가 꺼지면 게임도 꺼집니다.

## 파일 구조

```
server.js       서버 본체 (계정, 이동, 채팅 판정)
db.js           SQLite 저장소
game-data.js    드래곤 종류와 지도. 지역·종류 추가는 여기만 고치면 됩니다
public/index.html  게임 화면
data/game.db    게임 데이터 (처음 실행할 때 자동 생성)
```

## 데이터 백업

모든 데이터는 `data/game.db` 하나에 들어 있습니다. 서버를 끈 상태에서 이 파일을 복사해 두면 백업이 됩니다.
호스팅에 올릴 때는 `DB_PATH` 환경 변수로 영구 저장 공간 안의 경로를 지정하세요.

## 설정값

`server.js` 맨 위에서 조절할 수 있습니다.

- `MOVE_COOLDOWN` 연속 이동 간격 (기본 1.5초)
- `CHAT_COOLDOWN` 채팅 간격 (기본 0.7초)
- `HISTORY` 지역에 들어갈 때 보여줄 지난 대화 수 (기본 30개)
